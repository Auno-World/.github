# Security

## Reporting A Problem

If you find a security problem in any Aūno repository, please report it privately:

1. Open the repository on GitHub.
2. Go to the **Security** tab and choose **Report a vulnerability**.
3. Describe what you found and how to reproduce it.

Please don't open a public issue for security problems. You'll get a reply within seven days, and we'll keep you updated until it's fixed.

## What's In Scope

- Code in any public Aūno repository, including pages, scripts, and workflows.
- Anything that could expose a user's document or data, or run code they didn't expect.

## Good To Know

Aūno tools are built to run on your own computer with nothing uploaded. If you find a case where that isn't true, we especially want to hear about it.
