## Before You Build

A few habits that help anything from Aūno fit the way your company works.

1. **Pick the path that fits your company.** Some teams can use AI with their documents and some can't. Every Aūno tool has a way in that works either way, so choose the one your company is comfortable with.
2. **Know what you're running.** Everything here is plain and readable on purpose. Look through the files before you use them, and run your usual security scan on any code.
3. **Check your setup.** Some options only need a web browser. Others need something installed, like Python. Each tool lists what it needs up front.
4. **Start with the sample.** Every tool ships with fictional sample content. Get comfortable with it before you add real documents.
5. **Keep real information on your side.** The tools run on your own computer. When you share a bug or an idea, use sample content, not company documents.
6. **Tell us what you find.** Open an issue on the tool's page for a bug, or start a discussion for an idea or question. Every report gets read.
